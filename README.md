 🚀 InnovaTech – Premium Responsive Digital Agency Landing Page

Codveda Technologies | Front-End Development Internship | Level 1 – Task 1

A modern, visually engaging, and responsive digital agency landing page developed using **HTML5, CSS3, and Vanilla JavaScript** as part of the Codveda Technologies Front-End Development Internship.

The project demonstrates responsive web design, interactive user interfaces, modern CSS techniques, smooth animations, and front-end development best practices.

 ✨ Key Features

- Premium UI Design: Modern dark-themed interface with blue and purple gradients.
- Responsive Layout: Optimized for desktop, tablet, and mobile devices.
- Interactive Navigation: Responsive navigation bar with mobile hamburger menu.
- Hero Section: Engaging typography, modern imagery, and call-to-action buttons.
- Services Section: Responsive cards highlighting digital agency services.
- About Section: Introduction to the fictional InnovaTech digital agency.
- Portfolio Section: Featured digital project concepts.
- Contact Section: Contact call-to-action with an email link.
- Scroll Animations: Smooth reveal animations using JavaScript Intersection Observer.
- Active Navigation: Navigation links dynamically highlight the current section.
- Back-to-Top Button: Convenient navigation back to the top of the website.
- Accessibility Features: Semantic HTML, navigation labels, keyboard interactions, and reduced-motion support.

 💻 Installation & Local Setup

Step 1 – Clone the Repository

Run the following command in your terminal:

`git clone https://github.com/Rasindu12-web/Codveda-Level-1-Task-1.git`

**Step 2 – Navigate to the Project**

`cd Codveda-Level-1-Task-1`

Step 3 – Open the Project

Open the project folder using Visual Studio Code.

**Step 4 – Run the Website**

Open `index.html` in your browser or use the VS Code Live Server extension.

No additional frameworks, build tools, or package installation are required.

An internet connection is recommended to load external fonts and images.

 📱 Responsive Design

The website uses CSS Flexbox, Grid, and media queries to adapt its layout to different screen sizes.

- Desktop: Full navigation and multi-column layouts.
- Tablet: Adjusted spacing, stacked hero layout, and responsive cards.
- Mobile: Hamburger navigation, single-column layouts, and touch-friendly buttons.

 🔐 Security Practices

The project uses several basic front-end security practices:

- HTTPS delivery through GitHub Pages.
- Content Security Policy (CSP) defined through an HTML meta tag.
- Restricted script and resource origins.
- No database or server-side authentication.
- No sensitive credentials required by the application.

Note: This is a static front-end demonstration project. These measures are not a substitute for a comprehensive application security assessment.
